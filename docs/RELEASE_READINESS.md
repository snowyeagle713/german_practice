`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`. Earlier two-worker execution exposed timing sensitivity in
the cross-tab PWA update test; serialized execution passed. Default Playwright
configuration still has two workers; do not imply parallel execution is certified
stable. No new framework or dependency was added.

transaction writes suitable for the seed MVP, and no claimed migration to future
schemas. First successful production visit/preparation is required for offline
use. Root-origin hosting is expected; localhost preview is not external hosting.
